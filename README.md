<h1>Duplicate Question Detection Using NLP</h1>
A machine learning project that predicts whether two text questions are
duplicates (that is, whether they express the same or a very similar
meaning). The project uses natural language processing (NLP) and
supervised classification to compare question pairs.

🔗 Project Links
- Live Demo: https://duplicate-question-prediction-jfbi7qxigwv55dfotnfxxt.streamlit.app/



✨ Features
- Accepts two questions as input.
- Predicts whether the questions are duplicates or non-duplicates.
- Model Uses NLP and text-similarity features to help compare question
  pairs.
- It Displays a duplicate probability or confidence score, if enabled in
  the application.
- Includes a configurable decision threshold.
- Provides an interactive web interface for testing question pairs.
